# Assignment 5 — Employee File Processing

A file-processing exercise that stores employee records, reads them back, calculates salary statistics, sorts employees by salary, and rewrites the sorted data.

## Concepts
- File input/output
- Structures and vectors
- Sorting
- Maximum and average calculations
- Input validation

The cleaned version uses standard C++ strings and streams instead of the Visual Studio-specific `strcpy_s`, making it portable across modern C++ compilers.

`data/original-sample.txt` preserves the sample data from the original coursework.
